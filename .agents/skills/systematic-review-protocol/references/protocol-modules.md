# Protocol module checklist

Load only the active rows.

| Module | Eligibility core | Prespecify especially |
|---|---|---|
| Clinical intervention | PICOTS and eligible designs | effect measures, time points, adverse events, pooling |
| Observational association | population, exposure, comparator, outcome, design | confounders, adjusted estimates, temporality |
| AI diagnostic/prediction | intended use, population, model, target/reference, validation | validation type, performance metrics, thresholds |
| Preclinical/organ bath | species, tissue, conditions, exposure, comparator, outcome | units, bath conditions, normalization, repeated measures |
| Scoping/evidence mapping | population, concept, context, source types | charting fields, mapping dimensions, optional appraisal |

For a mixed review, assign every field and synthesis group to an owning module.
