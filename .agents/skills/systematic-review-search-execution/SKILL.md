# Search Execution

## Workflow

1. Verify the exact M2-approved strategy and platform.
2. Execute each search without scientific alteration. Record date, platform,
   interface, exact string, filters, result count, and export files.
3. Preserve raw exports byte-for-byte and assign source identifiers.
4. Document supplementary searching and unavailable sources separately.
5. Reconcile recorded counts with exported records. Route unexplained mismatch
   or a strategy-affecting platform change to humans.
6. Produce a validated search log and combined raw-record manifest.

Authentication and institutional-access actions remain human-controlled. A
format-only export conversion does not require a new approval.

When serializing shared artifacts, read [the contracts](../systematic-review/references/contracts.md); do not invent field names.

Finish `READY`; the next phase is deduplication.
